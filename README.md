# 📄 AI Resume Analyzer

An AI-powered Resume Analyzer built using Python, Streamlit, and Groq LLM API. This application allows users to upload resumes in PDF format and receive intelligent AI-based career insights including ATS score, skills analysis, improvement suggestions, and suitable job role recommendations.

---

# 🚀 Features

- Upload Resume PDF
- Resume Text Extraction
- AI-Based Resume Analysis
- ATS Score Prediction
- Technical Skills Identification
- Missing Skills Detection
- Resume Improvement Suggestions
- Career Recommendations
- Suitable Job Roles
- Interactive Streamlit Interface

---

# 🛠 Technologies Used

- Python
- Streamlit
- Groq API
- Llama 3.3 70B Model
- pdfplumber

---

# ⚙️ How It Works

1. User uploads a resume PDF.
2. The application extracts text from the resume.
3. Resume content is sent to the Groq LLM API.
4. AI analyzes the resume and generates:
   - Professional Summary
   - Technical Skills
   - Missing Skills
   - ATS Score
   - Improvement Suggestions
   - Career Recommendations
